## Project

Svelteup is a TypeScript package that bundles Svelte components into web components with esbuild.

## Commands

- Install dependencies with `pnpm install`.
- Build the package with `pnpm run build`.
- Run tests with `pnpm test`.
- Format files with `pnpm run format`.

## Notes

- Keep README examples aligned with the CLI in `bin.js` and the default options in `src/command/const.ts`.
- Do not commit generated `dist` changes unless the release flow requires them.
