# svelteup-chrome-extension

A Chrome extension starter powered by [svelteup](https://github.com/brandonxiang/svelteup). Example code is based on [Getting started for Chrome Extensions](https://developer.chrome.com/docs/extensions/mv3/getstarted/).

Use it to bundle Svelte custom elements for extension pages.

## Usage

```shell
# to develop
pnpm run dev

# to build
pnpm run build
```
