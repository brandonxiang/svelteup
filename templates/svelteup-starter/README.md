# svelteup-starter

A minimal starter for browser embeds and custom Svelte components, powered by [svelteup](https://github.com/brandonxiang/svelteup).

## Startup

```bash
pnpm i
pnpm dev
```

Add components under `src/` and import them from `src/index.js`.
